# Global Funds: Frequently Asked Questions (FAQ)

**For quick answers to common questions**

---

## Getting Started Questions

### Q: Do I need special permission to add a global fund?
**A:** Yes, you need admin credentials and access to the Global Funds module. If you can't see the Global Funds menu, contact your supervisor to request access.

### Q: Can I edit a fund after publishing it?
**A:** Yes! Click the edit (pencil) icon next to the fund name. You can change any field at any time. Changes take effect immediately.

### Q: Can I delete a fund?
**A:** Yes, but we recommend **not** deleting. Instead, uncheck "Visible on website" to hide it. This preserves historical data for compliance. Deletion is permanent and cannot be undone.

### Q: How long does it take for a new fund to appear on the website after I save it?
**A:** Usually 30 seconds to 2 minutes. If it doesn't appear after 5 minutes:
1. Check that "Visible on website" is checked
2. Clear your browser cache (Ctrl+Shift+Delete)
3. Refresh the website page
4. Try a different browser

## Field-Specific Questions

### Q: Is "Short Name" required?
**A:** No, it's optional. But it's recommended to add it for:
- Internal identification
- Reports and dashboards
- Marketing materials
- Quick reference

### Q: What's the difference between Fund Name and Short Name?
**A:** 
- **Fund Name:** Full, official name (e.g., "African Technology Growth Fund")
- **Short Name:** Abbreviated code (e.g., "ATGF" or "ATF")

### Q: How long can the Description be?
**A:** Technically unlimited, but keep it 300-500 characters (about 2-3 sentences). Longer descriptions get cut off on the website.

### Q: Can I copy&paste from another document to fill the Description?
**A:** Yes, but:
1. Paste plain text (no formatting)
2. Review for spelling
3. Make sure it's professional
4. Avoid copying marketing hype

### Q: What numbers should I use for Display Order?
**A:** 
- Use any numbers you want
- Lower numbers = earlier in the list
- **Best practice:** Use 10, 20, 30, 40... (allows room to insert funds later)
- **Avoid:** Sequential 1, 2, 3, 4... (makes inserting new funds difficult)

### Q: Can two funds have the same Display Order number?
**A:** Technically yes, but don't! Each fund should have a unique number so the order is clear. If two funds have the same number, the system may sort them unexpectedly.

## Performance Metrics Questions

### Q: Is it okay to not add any performance metrics?
**A:** Yes, technically you can save without metrics, but **don't**! Investors want to see performance data. Add at least:
- Fund Size
- YTD Return
- Any other relevant metrics

### Q: Can I update metrics monthly?
**A:** Yes! That's actually recommended. Create a calendar reminder to:
- Update monthly/quarterly: YTD Return
- Update annually: All returns, annual report, fund size
- Update immediately: Any major changes

### Q: What format should I use for percentages?
**A:** Any of these work:
- ✓ "15.5%"
- ✓ "15.5% p.a." (per annum)
- ✓ "15.5% annualized"
- ✓ "+15.5%" (for positive returns)

### Q: Can I include negative returns?
**A:** Yes, use "-5.2%" or "Loss 5.2%" depending on context.

### Q: What if the metric is not applicable to this fund?
**A:** Skip it! Not all funds have the same relevant metrics. Focus on metrics that actually matter for this fund.

## Document Questions

### Q: What document formats are supported?
**A:** 
- **Best:** PDF (.pdf)
- **Good:** PowerPoint (.pptx), Excel (.xlsx)
- **Avoid:** Word (.doc), uncompressed large files
- Convert to PDF if unsure

### Q: Can I upload the same document to multiple funds?
**A:** Yes, but rename each one slightly:
- Fund 1: "Factsheet_AGF_2026.pdf"
- Fund 2: "Factsheet_TIF_2026.pdf"
This makes it clear which document belongs to which fund.

### Q: Can I add external links instead of uploading?
**A:** Yes! Click "Add URL" and paste the web link. The system will link to the external document instead of hosting it. **Requirements:**
- URL must be publicly accessible
- No authentication required
- Link must not expire

### Q: What's the maximum file size I can upload?
**A:** Recommended: Under 5MB
- If larger, compress the PDF first (use tinypdf.com or similar)
- Or use "Add URL" to link to an external hosted file

### Q: When should I use "Add URL" instead of uploading?
**A:** Use "Add URL" when:
- File is large (>5MB)
- Document is hosted on another website
- You want the latest version automatically updated on the hosted site
- You don't want to re-upload updated documents

Use "Upload File" when:
- File is small (<5MB)
- Document is final/static
- You want AIB-AXYS to host the file
- Document doesn't change frequently

### Q: Can I delete a document after uploading?
**A:** Yes, click the delete (trash) icon next to the document in the list. You can delete and re-upload anytime.

## Visibility & Publishing Questions

### Q: What does "Visible on public website" checkbox do?
**A:** 
- ✓ Checked: Fund appears on the website for customers
- ❌ Unchecked: Fund is hidden (admin-only, customers can't see it)

### Q: Can I use this to create a "draft" fund?
**A:** Absolutely! Workflow:
1. Create fund with all details
2. **Uncheck** "Visible on website"
3. Send to manager for review
4. Make requested changes
5. When approved, **check** the box
6. Fund is now live

### Q: If I uncheck "Visible on website", will clients lose access to existing investments in this fund?
**A:** No! Existing client investments are NOT affected. This only hides the fund from new client inquiries. Clients with existing positions can still manage them.

### Q: Can I temporarily hide a fund for maintenance?
**A:** Yes! Uncheck "Visible on website" for the duration, then check it again when ready.

## Testing & Verification Questions

### Q: How do I test if my fund looks correct on the website?
**A:** 
1. Save the fund first
2. Go to: https://www.aib-axysafrica.com
3. Navigate to "Offshore Funds" or equivalent page
4. Look for your fund
5. **Verify:**
   - Fund appears in correct order (Display Order)
   - Name appears correctly
   - Description is visible
   - All documents download correctly
   - All links work
   - Looks good on mobile phone too

### Q: Why isn't my fund appearing on the website?
**A:** Check:
1. Is "Visible on website" checked?
2. Is Display Order numeric (not text)?
3. Did you save the fund?
4. Did you wait 2+ minutes?
5. Try clearing browser cache
6. Try on a different browser
7. Check if the website had server issues (ask IT)

### Q: What if the website shows old information?
**A:** This is usually a caching issue:
1. Clear browser cache (Ctrl+Shift+Delete for Windows)
2. Close all browser tabs
3. Reopen the website
4. Force refresh (Ctrl+F5)
5. If still old, wait a few minutes and try again

### Q: Can I test on a link before publishing?
**A:** If your organization has a staging/test website, yes. Otherwise:
1. Uncheck "Visible on website"
2. Ask QA team to verify
3. Check "Visible on website" to publish

## Management & Maintenance Questions

### Q: How often should I update fund information?
**A:** 
- **Monthly:** YTD Return numbers
- **Quarterly:** Performance metrics, monthly factsheet
- **Annually:** Annual report, full fund review
- **As needed:** Documents, strategy changes, contact info

### Q: Should I version-control document names?
**A:** Yes! Examples:
- ✓ "AGF_Factsheet_2026_Q1.pdf"
- ✓ "AGF_Annual_Report_2025.pdf"
- ✓ "AGF_Prospectus_v2.pdf"
- ❌ "Factsheet.pdf" (unclear which version)
- ❌ "Updated_Document.pdf" (when was it updated?)

### Q: Can multiple people manage the same fund?
**A:** Yes. The system tracks who created and last modified each fund. This is good for:
- Audit trails
- Accountability
- Compliance
- Knowing who to ask questions

### Q: What if I need to rename a fund after publishing?
**A:** That's fine! 
1. Edit the fund
2. Change the Fund Name
3. Save
4. Website updates automatically
5. Old name is overwritten (not visible to clients)

### Q: Can I merge two similar funds into one?
**A:** The system doesn't have an auto-merge feature, but you can:
1. **Option 1:** Delete the redundant fund (after backup)
2. **Option 2:** Archive by unchecking visibility
3. Copy metrics from one fund to another by editing
4. Consolidate documents into the main fund

## Permission & Access Questions

### Q: I don't see "Global Funds" in the admin menu. What do I do?
**A:** Contact your supervisor or IT team. You likely need:
- Admin credentials activated
- Global Funds permission granted
- Access tier increased (from user to admin)

### Q: Can I give someone else access to add funds?
**A:** No - you can't give permissions yourself. They need to contact IT/Admin. You can teach them how to use it once they have access.

### Q: What information appears in the audit log?
**A:** The system logs:
- Who created the fund (admin email)
- When it was created (timestamp)
- Who last modified it (admin email)
- When it was modified (timestamp)
- What changes were made

This is for compliance and security purposes.

## Security & Compliance Questions

### Q: Can clients edit or delete funds?
**A:** No! Only admins can edit/delete funds. Clients can only view published funds.

### Q: Is it okay to put sensitive financial data in the fund description?
**A:** No! Descriptions are public. Put sensitive data in:
- Password-protected PDF documents
- Private client portal
- Confidential email correspondence

### Q: Do I need to verify financial metrics are accurate?
**A:** Yes! Before publishing:
- Double-check all return percentages
- Verify against official source documents
- Get approval from finance team
- Ensure compliance with regulations

### Q: What if I accidentally published incorrect information?
**A:** 
1. **Immediately** edit the fund
2. Correct the information
3. Save changes
4. Notify clients/team of the error
5. Consider publishing a correction notice

### Q: Are fund documents encrypted or password protected?
**A:** Not by the system. If documents need protection:
- Password-protect the PDF before uploading
- Host sensitive docs externally (password-protected)
- Use "Add URL" to link to protected resource

## Troubleshooting Questions

### Q: I got an error "Required field missing" - what do I do?
**A:** 
1. Check that Fund Name is filled in
2. Check that Description is filled in  
3. Check that Display Order is a number
4. Look for any fields with red asterisks (*)
5. Fill in any empty required fields
6. Try saving again

### Q: The save button is greyed out/disabled - why?
**A:** Usually means:
1. Missing required field
2. Form validation error
3. Browser JavaScript issue

**Solution:**
1. Fill any empty required fields
2. Try refreshing the page
3. Try a different browser
4. Contact IT if persistent

### Q: Document upload shows "File too large" error
**A:** 
1. File is over 5MB
2. Compress the PDF (use online tool)
3. Try uploading compressed version
4. Or use "Add URL" instead to link externally

### Q: I can't find the fund I just created
**A:**
1. Did you save it? (Check for save confirmation)
2. Is "Visible on website" checked?
3. Did you remember Display Order?
4. Try refreshing the page
5. Try logging out and back in
6. Check if it appears further down the list

### Q: Changes I made aren't showing up on the website
**A:**
1. Did you click Save? (Very common to skip this)
2. Website may be cached - clear browser cache (Ctrl+Shift+Delete)
3. Close browser and reopen
4. Force refresh (Ctrl+F5)
5. Wait 5 minutes for database sync
6. Try on a different browser
