## 🏆 Common Scenarios

### Scenario 1: "Add a brand new investment fund"
**Documents to read:**
1. Quick Reference Card (checklist)
2. Step-by-Step Guide (detailed walkthrough)
3. Key point: Uncheck visibility to draft first, then publish

---

### Scenario 2: "Update performance metrics for quarterly report"
**Documents to read:**
1. Quick Reference Card (5 min reminder)
2. Step-by-Step Guide (Step 5: Performance Metrics)
3. Training Guide (Best Practices)
4. Key point: Edit, update only the metrics, save

---

### Scenario 3: "Stop offering a fund to new clients"
**Documents to read:**
1. Quick Reference Card (Visibility section)
2. Training Guide (Managing Funds - Hiding)
3. FAQ ("What if I need to hide a fund?")
4. Key point: Uncheck visibility, DON'T delete

---

### Scenario 4: "Train a new team member"
**Documents to share:**
1. Send Quick Reference Card first
2. Then Step-by-Step Guide
3. Go through together while they do it
4. Have them read Training Guide
5. Keep FAQ handy for questions
6. Let them practice independently
