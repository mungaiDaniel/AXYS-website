## 🚀 Adding a Fund in 5 Minutes

### The 5 Essential Fields:
1. **Fund Name** - Full name (e.g., "African Growth Fund")
2. **Description** - 2-3 sentences about the fund's strategy
3. **Display Order** - A number (10, 20, 30...) for sorting
4. **Performance Metrics** - At least one (e.g., "5-Year Return: 12.5%")
5. **Visible on Website** - Checkbox to publish/hide

---

## 📋 Field Descriptions at a Glance

| Field | What to Put | Example |
|-------|-------------|---------|
| Fund Name | Full fund name | "Tech Innovation Fund" |
| Short Name | Ticker/abbreviation | "TIF" |
| Description | Investment strategy & target investor | "High-growth tech stocks for investors aged 25-55 with 5+ year horizon" |
| Display Order | Sort number | 20 |
| Metrics | Label + Value | Label: "YTD Return" | Value: "18.5%" |
| Documents | Factsheets, reports | Upload PDF files |
| Visibility | Checkbox | ☑️ Visible = Public |

## 🏆 Pro Tips

### Tip 1: Use Spacing in Display Order
Instead of: 1, 2, 3, 4, 5  
Use: 10, 20, 30, 40, 50  
**Why:** Easy to insert new funds later without renumbering!

### Tip 2: Don't Delete, Hide Instead
Instead of deleting old funds → Uncheck "Visible on website"  
**Why:** Keeps historical data intact for compliance

### Tip 3: Consistent Descriptions
Keep all fund descriptions in similar format:
- **Sentence 1:** What it invests in
- **Sentence 2:** Who it's for
- **Sentence 3:** Key characteristics (risk level, term)

### Tip 4: Update Metrics Annually
Create a calendar reminder to update:
- Performance numbers (quarterly or annually)
- Fund size
- Documents (new annual reports)

### Tip 5: Test After Publishing
1. Save the fund
2. Go to the public website
3. Verify it appears correctly
4. Verify all documents are accessible
5. Check links work

## 🌐 Public Website Display

When a user visits the public website, they see:
- ✅ Fund Name (in list)
- ✅ Description (on fund detail page)
- ✅ Performance Metrics (in cards)
- ✅ Documents (links to download)
- ✅ Display Order controls position in list

Hidden from public (admin only):
- ❌ Created By / Last Modified By
- ❌ Visibility setting status
- ❌ Audit trail
